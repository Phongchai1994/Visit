# ระบบเยี่ยมญาติผู้ต้องขัง

ระบบจองเยี่ยมญาติโดยการสแกนลายนิ้วมือและอ่านบัตรประชาชน

## คุณสมบัติหลัก
- 📋 ลงทะเบียนผู้ต้องขัง
- 🔍 ค้นหาและจัดการข้อมูลผู้ต้องขัง  
- 📅 ระบบจองเยี่ยมญาติ
- 👆 สแกนลายนิ้วมือ (ZK Fingerprint Scanner)
- 💳 อ่านบัตรประชาชน (Smart Card Reader)
- 📊 รายงานการเยี่ยมรายวันและรายเดือน
- 🔐 เข้ารหัสฐานข้อมูล
- 📄 สร้างไฟล์ PDF รายงาน

## การติดตั้ง

### ติดตั้ง Dependencies
```bash
pip install -r requirements.txt
```

### รันโปรแกรม
```bash
python main.py
```

## ไฟล์สำคัญ
- `main.py` - ไฟล์หลักสำหรับเรียกใช้โปรแกรม
- `requirements.txt` - รายการ dependencies
- `INSTALL.md` - คู่มือการติดตั้งแบบละเอียด
- `config/config.json` - ไฟล์ตั้งค่าระบบ

## โครงสร้างโปรเจค
```
Visit/
├── main.py                 # ไฟล์หลัก
├── requirements.txt        # Dependencies
├── user_session.py         # จัดการ session ผู้ใช้
├── prisoners/              # โมดูลหลัก
│   ├── main_app.py        # หน้าหลักของแอป
│   ├── menu_app.py        # เมนูของแอป
│   └── card_reader.py     # อ่านบัตรประชาชน
├── manage/                 # จัดการระบบ
│   ├── database.py        # ฐานข้อมูล
│   ├── encryption_utils.py # เข้ารหัส
│   └── excel_to_db.py     # นำเข้า Excel
└── config/                 # ไฟล์ตั้งค่า
    └── config.json
```

## ข้อกำหนดระบบ
- Python 3.8+
- Windows 10/11  
- เครื่องอ่านบัตรประชาชน (Smart Card Reader)
- เครื่องสแกนลายนิ้วมือ (ZK Fingerprint Scanner)

เสียง
1 วางนิ้วที่ลงทะเบียนไว้ บนเครื่องสแกนลายนิ้วมือ
2 รอสักครู่ กำลังตรวจสอบข้อมูล
3 เลือกจองเยี่ยมวันนี้ หรือจองเยี่ยมล่วงหน้า
4 เลือกชื่อที่คุณต้องการจองเยี่ยมวันนี้
5 เลือกชื่อที่คุณต้องการจองเยี่ยมล่วงหน้า
6 เลือกรอบเยี่ยม แล้วกดเลือกผู้ติดตาม
7 เลือกผู้ที่จะเข้าเยี่ยมกับคุณ สูงสุด 4 คน แล้วกดถัดไป
8 ตรวจสอบข้อมูลให้ละเอียด และกดยืนยันการจองเยี่ยม หากต้องการแก้ไขให้กดย้อนกลับ
9 จองเยี่ยมสำเร็จ
